## Verification Strategy

Since this is a **UI interactivity** phase, the Verifier cannot fully automate
browser interaction from a terminal. Strategy:

1. **Static verification** of the built CSS for interactive states
   (`:hover`, `:active`, `:focus-visible`, `cursor:pointer`, `pointer-events`,
   transition/animation rules, `resize`/`drag` handlers).
2. **Boot the web app** (`dsh web`) and confirm it serves the interactive bundle.
3. **Check the JS bundle** for event handlers (onClick, onDrag, onMouseDown,
   ResizeObserver, useEffect listeners).
4. **Check CSS** for theme variables (`--dsw-*`, `--ds-*`) proving consistent theming.
5. **Check for render errors** — grep dist for `undefined`, `NaN` in template strings.
