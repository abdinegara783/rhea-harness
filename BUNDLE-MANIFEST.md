- **Tools/session/etc:** ~40 supporting packages (tools, session, fs, skill, terminal...)

## Deployment Decision

**Deploy the full `learn-harness/` monorepo** into `rhea-harness/` as a runnable
pnpm workspace. The `rhea-harness/` from Phase 0.1 already has `vendor/` +
`pnpm-workspace.yaml`; this phase overlays the rest of the monorepo on top so
all 58 workspace deps resolve at runtime.

## Notes for Integrator

- **Do NOT recompile.** Source `lib/` and `dist/` are pre-built — copy as-is.
- Preserve symlinks (e.g. `vendor/CLAUDE.md → AGENTS.md`).
- Skip `node_modules/` everywhere (will re-resolve via pnpm install in a later step if needed).

- The `pnpm-lock.yaml` is essential — copy it so `pnpm install` reproduces the exact dep graph.
