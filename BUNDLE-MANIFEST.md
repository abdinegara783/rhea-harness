## Acceptance Criteria

1. All 9 vendor package directories exist under `rhea-harness/vendor/`.
2. Each copied directory contains `package.json`, `LICENSE`, and `README.md`.
3. Each `package.json` retains its original `name`, `version`, and `license` fields.
4. `rhea-harness/vendor/` matches the 9 entries of `learn-harness/vendor/`.
5. Root `pnpm-workspace.yaml` (or a compatible workspace config) is present so the vendor packages form a resolvable workspace.

## Build Steps

1. Create `rhea-harness/vendor/`.
2. Copy each of the 9 vendor directories into `rhea-harness/vendor/<name>/`.
3. Copy `pnpm-workspace.yaml` (workspace root) so `vendor/*` members resolve.
4. (Optional for this phase) No build/compile required — packages ship source; later phases compile.

## Notes for Integrator

- Do **not** rename any package or rewrite `package.json` `name` fields (Compliance: branding rules, Phase 0.1 allows `@deepseek-ai/*` scoped names as package identifiers — they are NOT UI strings).
- Preserve symlinks if any (e.g. `vendor/cordis/CLAUDE.md → AGENTS.md`).
- Skip `node_modules` and any `dist/` or build artifacts.
- Do not modify source code in this phase.
